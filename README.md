# TunjoVivo · Piedras del Tunjo

Sitio de reservas para el **Parque Arqueológico Piedras del Tunjo**, operado por TunjoVivo.
*La historia cobra vida en cada aventura.*

## Qué incluye

- Página de una sola carpeta (`index.html`), lista para GitHub Pages.
- Tres planes de visita: Familiar, Deportivo y Estudiantil.
- Secciones de Visita, Historia y Contacto con mapa.
- Carrito con selección de fecha, guardado en el navegador (`localStorage`).
- Contacto directo por WhatsApp.

## Cómo verlo localmente

Abre `index.html` en tu navegador — no necesita servidor.

## Cómo publicarlo en GitHub Pages

1. En GitHub, entra a este repo → **Settings** → **Pages**.
2. En *Source*, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. En uno o dos minutos la página queda publicada en
   `https://leooo2k04.github.io/piedras-del-tunjo/`.
